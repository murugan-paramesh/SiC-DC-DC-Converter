# Experimental_Datasets

**Empty by design.** No converter has been built and no measurement exists. This folder is reserved for
HIL and laboratory data. Every dataset added here must carry: instrument list with calibration dates, bandwidth
and probe setup, operating-point table, raw files plus the processing script, uncertainty budget, and a
provenance.json (who, when, which hardware revision, which firmware commit). Synthetic data never go here; they
stay in the module that generated them, labelled SYNTHETIC.
