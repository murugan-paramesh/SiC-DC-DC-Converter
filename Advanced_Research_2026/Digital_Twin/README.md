# Digital twin: hierarchical model + online parameter estimation + self-optimising supervisor

**Maturity: L2 (simulation-validated), L3 for the estimator code (deterministic tests below).
No hardware, no HIL. All data are generated by the project's switched plant model and are labelled
SIMULATED; the transition-time sensor of E3 does not exist on the current board (proposal).**

This is the primary research contribution A of `../00_Gap_Analysis_and_Plan.md`: physics-informed
adaptive soft-switching control, built as a four-layer twin of the 6.6 kW SiC DAB.

| Layer | Content | File | Maturity |
|---|---|---|---|
| L1 electrical | period-average DAB model on the *applied PWM pattern*; every current scales with 1/L | `twin.py: discrete_model, discrete_model_lossy` | L2 |
| L2 thermal | 2-node Foster network per bridge, Kalman observer of Tj from the case NTC | `twin.py: ThermalTwin` | L2 (capacitances ESTIMATED) |
| L3 health | Rds_on / Coss drift as slowly varying parameters (see observability) | `twin.py`, `../SiC_Health_Monitoring` | L1-L2 |
| L4 supervisory | operating-point selection on the estimated parameters inside the validated envelope, deterministic fallback | `supervisory.py` | L2 |

Estimators: RLS with forgetting and excitation gating, EKF with joint state [v2, i_load, 1/L],
sequential grid Bayes (reference), Coss_er RLS on a proposed transition-time measurement.

## 1. Observability (which parameters can the sensors on the board identify?)

`observability.py` computes the Fisher information of p = [L, Coss_er1, Coss_er2, R_s] from finite-
difference sensitivities of the switched plant at 36 operating points (3 V1 x 3 V2 x 4 phase shifts,
EPS matching) with the sensing-chain noise of the schematic (12-bit ADC, 0.3-1 % gain classes).

| Sensor set | rank of F | Cramer-Rao relative std after 1000 periods (noise only) |
|---|---|---|
| LV shunt I2_avg only (on board) | 2 | L 0.03 %, R_s 8 %, Coss: **not identifiable** |
| + HV CT I1_avg (on board) | 2 | L 0.03 %, R_s 7 % |
| + peak detector (on board) | 2 | L 0.03 %, R_s 0.7 % |
| + proposed HV drain transition-time sensor | 3 | L, Coss_er1 0.03 %, R_s 0.06 % |
| + proposed LV transition-time sensor | 4 | all four |

Result: with the sensors that exist, **L and (weakly) the loss resistance are identifiable; the output
capacitances are not** - the period-average quantities have zero sensitivity to Coss. A ZVS-margin
or transition-time measurement (drain-voltage slope comparator or a desaturation-style timing
sense) is required for the capacitance branch of the adaptive law; it is proposed, not built.

## 2. Estimation study on simulated data (`run_twin_study.py`, `results/twin_study.json`)

| Experiment | Set-up | Result |
|---|---|---|
| E1 L identification | true L = 0.8 L_nom then +15 % drift over 30 ms; 100 -> 50 % load step; estimators start at L_nom | RLS and EKF converge within the first logged sample (< 0.1 ms) and track the drift with 0.24 % / 0.25 % final error; RLS 1-sigma 0.9 % |
| E2 light-load conditioning | steady state at 100 / 30 / 10 % load, true L = 0.9 L_nom | bias +0.6 % / -0.9 % / -0.5 % (loss resistance R_s is not in the lossless regressor); gating (regressor < 2.5e-4 A*H) holds the estimate at 10 % load (141 of 4000 updates) and removes the light-load spread (ungated: 0.03 % std, -0.8 % bias) |
| E3 Coss_er (proposed sensor) | true Coss = 1.2 x datasheet, true L = 0.85 L_nom, 50 % load, synthetic 5 ns rms timing noise | +4.5 % error with the estimated L, -11.6 % with the nominal L: the capacitance estimate inherits the inductance error, so the two branches must run together |
| E4 thermal twin | loss steps 6 -> 14 -> 4 W per device, observer with +15 % RthJC and +10 % loss error, NTC noise 1 K | Tj error 1.1 K rms, 1.6 K steady, 14 K peak during the step (observer lag + model error; the NTC noise is not the limit) |

Figures: `results/E1_L_identification.png`, `E3_Coss_identification.png`, `E4_thermal_twin.png`.

**Baseline defect found by this study (fixed in the engineering baseline).** The first E3 run
showed a 13 A DC inductor current whenever the inner phase shift was below 1. Cause: the switched
plant (`dabtools/dab/sim_switched.py`) built the positive and negative pulses of a three-level bridge
voltage from two independent floating-point comparisons, which can differ by one time step when a
pulse edge falls on a cell centre; the resulting DC volt-second per period drives a DC current through
the loop resistance. The negative pulse is now the positive one rolled by exactly N_sub/2 cells.
`05_Simulation/run_switched_sim.py` was re-run: the headline results move by < 0.3 V / < 0.1 % (the
affected cases were the EPS/dead-bus ones), see the verification report. The second artefact of the
plant - the 200-step time quantisation of the modulator - is handled by evaluating the regressor on the
applied pattern (the controller knows its PWM registers); without this the estimate was 4-7 % off at
small phase shifts.

## 3. Supervisory self-optimisation (`supervisory.py`, `results/supervisory_study.json`)

27 operating points (V1 650/800/850 V x V2 300/400/450 V x 10/30/100 % power) on the switched plant
with the true L 20 % below nominal. The supervisor chooses (D1, D2) from a 16-candidate grid around
EPS voltage matching to minimise the model rms current subject to a 1 A ZVS margin on both bridges
and the 32 A peak limit, using the estimated L; the PI loop sets phi. Fallback to the fixed EPS
schedule when the estimate's 1-sigma exceeds 5 %, lies outside 0.7-1.3 L_nom, or the operating point
leaves the envelope (0 of 27 here, by construction of the test).

| Metric (measured on the plant) | fixed EPS schedule (nominal L) | adaptive supervisor (estimated L) |
|---|---|---|
| rms current, mean change | - | -2.3 % (best -19.8 % at 800 V / 300 V / 10 %, worst +16 % at 850 / 400 / 30 %) |
| points with at least one hard-switched edge | 19 of 27 | 16 of 27 |
| hard-switched edges, total over the 27 points | 61 | 56 |
| rms prediction error of the nominal-parameter model | -10.5 % mean, 22.6 % max | (estimated-parameter model: within the E1/E2 bias) |

Honest reading: the largest, unambiguous benefit of the twin is *prediction accuracy* (the nominal
model under-predicts the rms current by 10 % on average when L is 20 % low, which also shifts every
ZVS boundary). The D-grid supervisor gives a modest average rms reduction and does not remove
light-load hard switching, which is a property of the DAB at 10-30 % load with SPS/EPS - a light-load
strategy (TPS search, frequency modulation or burst mode) is needed and is covered by the ZVS maps in
`../Adaptive_MPC`. At two points the supervisor's choice was worse on the plant than the fixed
schedule, because the model's ZVS feasibility differs from the plant's at the inner edges; a larger
margin or the lossy model should be used there (reported, not hidden).

## 4. Software interface (`interface.md`)

Telemetry frames (CRC-16, 1 kHz) from the firmware carry the period-average measurements and the
applied PWM registers; the twin runs on the host and sends parameter updates and the (D1, D2) choice
back as *advisory* commands that pass the same limiter as the fixed schedule. See `interface.md`.

## 5. What was NOT verified

* No hardware, no HIL: every number above is from the project's switched plant with modelled sensors.
* The transition-time sensor (E3) is a proposal; its 5 ns noise figure is assumed.
* Thermal capacitances and heat-sink resistance are estimates; the observer error is dominated by
  the RthJC / loss-model errors, which only a calibration on hardware can reduce.
* The regressor neglects the loop resistance (0.6-0.9 % bias) and the dead time (the plant has none).
* C2000 timing of the RLS update (one multiply-accumulate chain per period) is estimated in
  `../Embedded_AI`, not measured.
